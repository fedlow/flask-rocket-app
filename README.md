# 🚀 Flask Rocket App

Учебное веб-приложение на микрофреймворке **Flask**, созданное в рамках выполнения домашнего задания по основам веб-разработки.

## 📝 Описание проекта
Главная страница приложения содержит:
* Приветственный заголовок (`<h1>`).
* Текст-описание приложения (`<p>`).
* Изображение космической ракеты.
* Внешний файл стилей (`CSS`) для центрирования элементов, изменения шрифтов и добавления визуальных эффектов.

## 🛠️ Технологии
* **Python 3**
* **Flask** (микрофреймворк)
* **HTML5**
* **CSS3**
* **Jinja2** (шаблонизатор, встроенный в Flask)

## 📂 Структура проекта
flask-rocket-app/
│
├── app.py                  # Главный файл приложения Flask
├── README.md               # Описание проекта (этот файл)

│   └── index.html          # Главная страница сайта
│
